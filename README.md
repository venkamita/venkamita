### 🔨 Projects

* **[Self-Correcting Text-to-SQL Agent](https://github.com/venkamita/self-correcting-text-to-sql):**
  Built an agentic Text-to-SQL pipeline using PydanticAI and Ollama with a dedicated repair agent that validates failed queries against schema and query intent. Tested and fixed failure cases involving column projections, JOIN semantics, and nested aggregation.

* **NIFTY-50 Delta-Space Hybrid Ensemble Forecasting:**
  Developed a delta-space stacked ensemble using LSTM, CNN, and TCN models, benchmarking 13 meta-learners on 11 years of NIFTY-50 OHLC data. The best configuration achieved **R² = 0.989** with a **48.7% RMSE reduction** over the strongest standalone model.

* **[Framework-Free Retrieval-Augmented Generation (RAG) System](https://github.com/venkamita/rag-from-scratch):**
  Built an end-to-end RAG system from scratch without LangChain or managed vector databases. Combines **BM25 sparse retrieval, dense embeddings, and Reciprocal Rank Fusion (RRF)** with grounded generation and chunk-level citations.

* **[EDA on San Antonio Spurs](https://github.com/venkamita/EDA-on-San-Antonio-Spurs-for-last-three-seasons):**
  Explored NBA data from the San Antonio Spurs, combining my interest in basketball and data analysis.

* **[SpotifyAI Playlist Generator](https://github.com/venkamita/SpotifyAI--A-website-that-suggests-music-using-OpenAI-API-key):**
  Built an AI-powered playlist generator during a hackathon, using an LLM to generate personalized music recommendations.
